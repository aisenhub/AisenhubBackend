# Phase Checkpoints

At each completed phase, create `PHASE-00.md`, `PHASE-01.md`, and so on with: Phase, Completed Tasks, Delivered Functionality, Migrations Added, API Added, Tests Added, Quality Gate Results, Known Limitations, Deferred Items, Architecture Deviations, Human Interventions, Git Range, and Next Phase.

`Architecture Deviations` must be `None` unless an approved architecture change is linked.
