# Legacy V1 — Curated Historical Archive

Status: superseded.

The original V1 was a multi-product platform built around Global Profile, Applications/Origins, Platform Cookie Session, Catalog, Entitlement, Redemption, Commerce and Admin. Its business-domain/security work was valuable; its shared Platform Session / Origin-auth topology is no longer the target.

This curated archive keeps the design/task lineage and exact source identifiers. Process diaries, checkpoints, reports and one-off environment snapshots are intentionally not copied into the new docs tree.
